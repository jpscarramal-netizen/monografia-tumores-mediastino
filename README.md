# Monografia: estado atual do tratamento cirúrgico dos tumores mediastinais

Trabalho do Grupo 6, CGP012 Clínica Cirúrgica II, Medicina UFOP, 2026/2.

**Para um Claude Code assumir o projeto:** use o prompt de [`PROMPT.md`](PROMPT.md).

| Arquivo / pasta | Conteúdo |
|---|---|
| `CLAUDE.md` | regras da pasta (lidas automaticamente pelo Claude Code) |
| `PROJETO.md` | estado, decisões fechadas, pendências |
| `HANDOFF.md` | onde a última sessão parou e o próximo passo |
| `PLANO.md` | plano completo: recorte, PICO, busca, estrutura, etapas, formatação |
| `PROMPT.md` | prompt de entrada para uma sessão nova |
| `entrada/normas/` | normas da disciplina (Moodle) |
| `entrada/exemplo-semestre-anterior/LEIA.md` | estrutura da monografia aprovada no semestre passado (PDFs só locais) |
| `trabalho/` | buscas, triagem, extração, rascunhos |
| `saida/` | monografia final (.docx) |

Repositório público. PDFs de artigos (direito autoral) e o trabalho dos colegas ficam só no
computador do JP (ver `.gitignore`); o formato do exemplo está descrito em
`entrada/exemplo-semestre-anterior/LEIA.md`. Artigos baixados vão para `entrada/artigos/`, também fora do git.
